# Travel Booking System

## Deskripsi
Travel Booking System adalah aplikasi konsol berbasis Java yang mensimulasikan sistem pemesanan perjalanan seperti Traveloka atau Tiket.com. Aplikasi ini memungkinkan pengguna untuk mencari penerbangan, mencari hotel, melakukan pemesanan, membatalkan reservasi, dan melihat semua reservasi.

## Fitur
1. Search Flight
2. Search Hotel
3. Book Flight
4. Book Hotel
5. Cancel Reservation
6. View All Reservations
7. Input Validation and Error Handling
